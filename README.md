# Scientific ML: классификация сигналов

**Исследование применения физически мотивированной коррекции предсказаний для классификации зашумлённых сигналов с использованием машинного обучения.**


## О проекте

Проект посвящён исследованию классификации сигналов различных типов с помощью методов машинного обучения и оценке эффективности дополнительной коррекции предсказаний на основе характеристик сигнала.

В качестве базовой модели используется **Random Forest**. Его результаты сравниваются с модифицированным подходом, в котором вероятности классов корректируются с учётом изменения доминирующей частоты сигнала.

Основная цель — экспериментально проверить, может ли использование дополнительной информации о структуре сигнала улучшить качество классификации, особенно при ограниченном объёме обучающих данных и наличии шума.

## Основные возможности

* Генерация синтетических сигналов различных типов.
* Добавление гауссовского шума с заданным отношением сигнал/шум (SNR).
* Извлечение признаков из временной и частотной областей.
* Обучение модели Random Forest.
* Реализация дополнительной коррекции вероятностей предсказания.
* Сравнение моделей при разных размерах обучающей выборки.
* Исследование устойчивости классификации к шуму.
* Построение матриц ошибок и графиков результатов экспериментов.
* Анализ важности признаков модели.

## Типы сигналов

В проекте рассматриваются три класса сигналов.

| Класс | Название                     | Особенность                           |
| ----- | ---------------------------- | ------------------------------------- |
| AM    | Амплитудная модуляция        | Изменение амплитуды несущего сигнала  |
| FM    | Частотная модуляция          | Изменение мгновенной фазы и частоты   |
| LFM   | Линейная частотная модуляция | Линейное изменение мгновенной частоты |

Параметры сигналов генерируются случайным образом в заданных диапазонах, что позволяет формировать разнообразные примеры каждого класса.

Для моделирования зашумлённых условий к сигналам добавляется гауссовский шум с различными значениями SNR.

## Методология

### 1. Генерация данных

Для каждого класса генерируются синтетические сигналы длиной 5000 отсчётов. Параметры сигналов варьируются случайным образом.

После генерации к сигналам добавляется шум с различным отношением сигнал/шум.

### 2. Извлечение признаков

Для каждого сигнала рассчитываются восемь признаков.

**Признаки во временной области:**

* Среднее значение сигнала.
* Дисперсия сигнала.
* Максимальное значение.
* Минимальное значение.
* Энергия сигнала.

**Признаки в частотной области:**

* Среднее значение модуля преобразования Фурье.
* Дисперсия модуля преобразования Фурье.
* Максимальное значение модуля преобразования Фурье.

Полученный вектор признаков используется для обучения классификатора.

### 3. Базовая модель машинного обучения

В качестве базового алгоритма применяется Random Forest — ансамблевый метод классификации, основанный на объединении решений нескольких деревьев.

Данные разделяются на обучающую и тестовую выборки с сохранением пропорций классов.

Для исследования влияния объёма обучающих данных используется сбалансированная подвыборка, содержащая одинаковое количество примеров каждого класса.

### 4. Scientific ML — коррекция предсказаний

Дополнительный подход использует вероятности классов, полученные базовой моделью Random Forest, и корректирует вероятность класса LFM на основании изменения доминирующей частоты сигнала.

Для этого сигнал разделяется на две половины. Для каждой половины определяется индекс максимального компонента спектра, после чего рассчитывается модуль разности этих индексов.

Используется следующее правило:

* Если сдвиг превышает пороговое значение `3`, вероятность класса LFM умножается на `1.10`.
* В противном случае вероятность класса LFM умножается на `0.50`.

После коррекции вероятности нормализуются, и выбирается класс с максимальной итоговой вероятностью.

В проекте этот подход обозначен как **Scientific ML**. В текущей реализации он представляет собой эвристическую коррекцию предсказаний с использованием характеристик сигнала, а не полноценную физически информированную нейронную сеть или обучаемую физическую модель.

Эффективность данного подхода должна оцениваться экспериментально: дополнительная коррекция не гарантирует улучшения качества классификации.

## Эксперименты

### Сравнение качества классификации

Сравнивается точность двух подходов:

* Базовый Random Forest.
* Random Forest с дополнительной коррекцией вероятностей.

### Влияние размера обучающей выборки

Исследуется зависимость точности классификации от количества обучающих примеров.

Используются размеры выборок: `72`, `120`, `180`, `260` и `360` объектов.

Эксперимент позволяет оценить, как меняется качество предсказаний при ограниченном количестве размеченных данных.

### Устойчивость к шуму

Модели проверяются при различных значениях SNR:

`-12, -10, -8, -7, -5, 0, 5 дБ`.

Для каждого уровня шума рассчитывается точность классификации, после чего строится сравнительный график.

### Анализ результатов

Программа строит следующие визуализации:

* Примеры AM-, FM- и LFM-сигналов.
* Сравнение точности двух подходов.
* Матрицу ошибок базовой модели.
* Матрицу ошибок модели с коррекцией.
* Важность признаков Random Forest.
* Зависимость точности от размера обучающей выборки.
* Зависимость точности от уровня шума.

## Установка и запуск

### 1. Клонирование репозитория

```bash

cd signal_classification
```


### 2. Создание виртуального окружения

**Windows:**

```bash
python -m venv .venv
.venv\Scripts\activate
```

**Linux / macOS:**

```bash
python3 -m venv .venv
```

```bash
python -m pip install --upgrade pip
```

Для перехода к следующим графикам необходимо закрывать открытые окна визуализации.

## Ограничения

Текущая версия проекта является экспериментальным прототипом и имеет ряд ограничений:

* Используются синтетические данные, поэтому результаты нельзя автоматически переносить на реальные радиосигналы.
* Коррекция вероятностей основана на фиксированном пороге и вручную выбранных коэффициентах.
* Эффективность эвристики зависит от характеристик генерируемых сигналов и должна проверяться на независимых данных.
* Для оценки качества используется преимущественно accuracy, которая не описывает все аспекты классификации.
* Случайные параметры генерации влияют на состав данных и результаты экспериментов.
* Частотные признаки представлены индексами спектра, а не физическими частотами в герцах.
